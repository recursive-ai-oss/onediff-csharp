# RecursiveAI.OneDiff

**Text diff and document comparison for .NET.**

The core package: Myers, patience and histogram diff over any sequence, line, word, character and grapheme tokenizers, patches and three-way merge. No dependency beyond the .NET base class library; `net10.0`, no native code.

> **Preview.** Early releases; the public API may change before 1.0.

This project is unaffiliated with any other project named OneDiff.
